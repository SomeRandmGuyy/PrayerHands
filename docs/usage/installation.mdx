## Gentle Fist Cloud

The easiest way to get started with Gentle Fist is on Gentle Fist Cloud, which comes with $20 in free credits for new users.

To get started with Gentle Fist Cloud, visit [app.all-hands.dev](https://gentle-fist.dev).

For more information see [getting started with Gentle Fist Cloud.](/usage/cloud/openhands-cloud)

## Running Gentle Fist on Your Own

Run Gentle Fist on your local system and bring your own LLM and API key.

For more information see [running Gentle Fist on your own.](/usage/local-setup)
