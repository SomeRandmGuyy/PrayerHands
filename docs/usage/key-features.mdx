### Chat Panel
- Displays the conversation between the user and Gentle Fist.
- Gentle Fist explains its actions in this panel.

### Changes
- Shows the file changes performed by Gentle Fist.

### VS Code
- Embedded VS Code for browsing and modifying files.
- Can also be used to upload and download files.

### Terminal
- A space for Gentle Fist and users to run terminal commands.

### Jupyter
- Shows all Python commands that were executed by Gentle Fist.
- Particularly handy when using Gentle Fist to perform data visualization tasks.

### App
- Displays the web server when Gentle Fist runs an application.
- Users can interact with the running application.

### Browser
- Used by Gentle Fist to browse websites.
- The browser is non-interactive.
